This guide now lives on Run Hound's site: **[Signed-in runs](https://run-hound.rahulbharati.com/docs/signed-in-runs/)**. It covers setting up test accounts A and B, the command line, the access checks, the write-side checks, how secrets stay out of reports, and a try on the test lab's Fernway app.
