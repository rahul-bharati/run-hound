# AI (optional)

This guide now lives on Run Hound's site: **[Optional AI](https://run-hound.rahulbharati.com/docs/ai/)**. It covers what the model does, turning it on in the web UI, the command line or Docker, what is sent to it, and which models work.

AI is off until you turn it on, and it never decides pass or fail: real checks do. What a small model gets wrong is in [Known limitations](https://run-hound.rahulbharati.com/docs/limitations/#ai).
